# ICS 233 - Open Action Tracker

The ICS 233 keeps track of tasks the Incident Commander (or Unified Command) hands out that are not incident
objectives. Incident objectives go on the [ICS 202](help:forms/ics202/index). Examples are "confirm the hotel rates
with the province" or "get a map of the evacuation zone to the PIO".

- **Kept by:** the Planning Section Chief, often with help from the Documentation Unit Leader. The IC, Unified Command
  and Deputy IC can also add and change actions.
- **Who sees it:** everyone in the incident can read it. Bring it to the Command and General Staff and Planning
  meetings so each person can report on their actions.

There is **one list for the whole incident**. Open actions carry over from one operational period to the next until
they're done.

## Adding an action

| Block | What to enter |
|---|---|
| 2. No. | Given for you, in order. |
| 3. Item | A short description of the task. |
| 4. For / POC | The **position** responsible, picked from the positions filled in the incident. You can add a name or note, or leave the position blank and type who it's for. |
| 6. Start date | When the task was given. Defaults to today. |
| 7. Status | Where it stands, for example "Awaiting feedback". |
| 8. Target date | When it should be done. |

When you pick a position, everyone holding it gets a notice under **My action items** on the dashboard.

## Keeping it up to date

- **5. Briefed:** the POC presses **I've been briefed** once they know about the task. This matters for tasks given out
  when the POC wasn't in the room. The keeper can also press **Mark briefed**.
- **Status:** the POC or the keeper types a new status and presses **Update**.
- **Done:** tick **Completed** and press **Update**. The action moves to **Completed actions** with today's date as
  **9. Actual date**, and whoever added it is told. The keeper can **Reopen** it.
- **Edit** changes any part of an action. **Remove** takes it off the tracker. Both are recorded in the audit log.

Rows turn **yellow** when the target date is today or tomorrow, and **red** once it has passed.

## Printing

- **Preview PDF** and **Download PDF** print the open actions on the official ICS 233.
- **PDF with completed** prints all of them.

The form has 34 numbered rows per page. When an action's own number differs from the printed row number, it's shown
in front of the item ("No. 12: ...").

# Lookup lists

Local values that forms **suggest as you type**. People can still type something else, and changing a list never
changes forms already filled in. **Disable** a value to stop suggesting it; it stays on any form that used it.

## The lists

| List | Where it's suggested |
|---|---|
| Agencies | ICS 211 "Home Unit / Agency", position assignments (Agency), the ICS 213RR and Resources Unit "Supplier" boxes |
| Jurisdictions | ICS 209 block 20 (Incident Jurisdiction) and block 21 (Incident Location Ownership) |
| Incident Types | "Incident Type" when setting up an incident |
| Facility Types | The facility types on the [Facilities](help:forms/facilities/index) page |
| Contact Categories | Not used yet (planned for the Liaison agency register) |

## Contact details

**Agencies** and **Jurisdictions** can hold contact details: main phone, 24/7 emergency line, email, website and
notes. Add them when you add a value, or press **Edit** on an existing one. Tick **I checked these contact details
today** whenever you confirm them; the date and your name are recorded, and anything not checked in 12 months is
flagged in the [Agency Directory](help:forms/directory/index).

Keep these to **organization** contacts: main lines, 24/7 lines and general mailboxes. A named person's own cell
number is personal information under Alberta's Protection of Privacy Act. It belongs in the incident's
[ICS 205A](help:forms/ics205a/index), not in a list every user can see.

When someone picks an agency in a suggestion box, its phone numbers show next to the name.

**Incident Types** and **Facility Types** come with defaults. **Jurisdictions** start empty: add your municipality,
its neighbours, nearby First Nations and the province.

## Starter lists

Agencies differ by province, so they aren't added for you. Under **Starter lists**, pick your province and press
**Load starter list** to add common organizations: the provincial emergency management agency, police, EMS,
utilities, railways, the Red Cross and others. It only adds values that aren't there yet, so loading it again never
undoes your changes. Review the list afterwards: names change over time, and each starter list shows when its names
were last checked. Only Alberta is available so far. Starter lists don't include phone numbers: numbers change,
and a wrong number on an emergency list is worse than a blank one. Add and verify them yourself.

## Lists no longer used

**Facilities**, **Resource Kinds**, **Resource Types** and **Positions** used to be here. They're now kept on the
Facilities page, the [Resource Catalogue](help:admin/resource_catalogue) and the [Role Catalogue](help:admin/role_catalogue).
Any old values are still shown, marked "no longer used", but forms don't offer them.
